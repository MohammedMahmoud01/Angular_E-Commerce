# 🛒 E-Commerce Web Application (Angular + ASP.NET Core)

A full-stack e-commerce platform built with **Angular**, **ASP.NET Core**, and **SQL Server**.  
It provides a complete online shopping experience with product browsing, cart, checkout, authentication, and an admin panel.

## 🚀 Features
- Dynamic homepage with promotional sliders
- Product details with images, descriptions, and related items
- Category-based product pages with pagination
- Shopping cart with checkout process
- User authentication & profile management
- Admin panel to manage products, categories, sliders, and images

## 🛠️ Tech Stack
- **Frontend:** Angular  
- **Backend:** ASP.NET Core Web API  
- **Database:** SQL Server
